# 1943: The Battle of Midway (航母升空 ‧ 魔王登場 ‧ 逐關遞增 ‧ 戰役過關報告版)

本遊戲以 Capcom 經典街機名作《1943: 中途島海戰》為靈感與藍本，全新加入了**航母彈射升空動畫、逐關彈幕難度漸進提升、魔王登場艦隊規格介紹、擊沉旗艦全名確認、擊落敵機掉落加分金星 (⭐)、過關戰役數據結算報告與戰績英雄榜**等全套經典街機機制！

---

## 🌟 遊戲核心特色與重大升級

1. **🚢 航母甲板彈射升空動畫 (Carrier Takeoff Intro)**：
   - 投幣開始遊戲時，雙機置於企業號航空母艦（USS Enterprise CV-6）木質飛行甲板中央。
   - 引擎轟鳴預熱震動 ➜ 蒸汽彈射器瞬間全力加壓 ➜ 雙機急速俯衝衝出跑道破空升空，伴隨航母尾流與壯闊海浪滾滾後退，正式開啟第一關突擊！

2. **📈 逐關難度平穩遞增 & 彈幕漸進微調**：
   - **STAGE 1（突入中途島海域）**：極度溫和，同屏子彈上限僅 **6 顆**，慢速射擊，新手玩家也能輕鬆閃避走位。
   - **STAGE 2（珊瑚海截擊作戰）**：同屏子彈上限 **9 顆**，敵機增加雙發點射。
   - **STAGE 3（鐵底海峽夜戰）**：同屏子彈上限 **12 顆**，敵艦主砲開始進行扇形壓制。
   - **STAGE 4（馬里亞納海空戰）**：同屏子彈上限 **15 顆**，空母防空高射陣地強化。
   - **STAGE 5（雷伊泰灣終極決戰）**：同屏子彈上限 **18 顆**，大和戰艦九門巨砲與多層密集防禦火網。
   - **無時間扣油壓力**：血量/能量僅在實際受到攻擊或撞擊時才會減少，取消了自然燃料扣除。

3. **🚨 魔王登場規格介紹卡 (Cinematic Boss Dossier)**：
   - 每一關最終魔王出現前，防空防暴警報長鳴！
   - 畫面中央投射復古戰術情報卡：揭示**敵旗艦全名、艦種 classification、艦身長度、排水量與重武裝配置**，重現大決戰臨場感！

4. **💥 擊破確認與擊沉全名宣告 (Boss Sunk Confirmation)**：
   - 魔王血量歸零時，引發連環核爆級震動與水花火海，畫面中央巨幅宣告：  
     **【擊破確認】STAGE X: 重巡洋艦「利根」/ 航空母艦「加賀」... 徹底擊沉！**

5. **⭐ 加分金星掉落機制 (Collectible Golden Stars)**：
   - 擊墜完整的 5 機「紅色編隊」：必定同時爆出 `POW` 補給與加分金星！
   - 擊毀「中型長程轟炸機」：掉落 1 顆加分金星。
   - 擊沉「驅逐艦」或「中途島中隊長機」：掉落 2 顆加分金星。
   - 撿取每顆金星獲得 **+2,000 分** 與悅耳叮噹音效，並納入關卡結算！

6. **📊 戰役過關數據報告 (Stage Debriefing Report)**：
   - 擊破關底魔王後，彈出完整的戰功結算報告：
     - ✈️ **擊落敵機數** (每架 +500 PTS)
     - ⭐ **獲取星星數** (每顆 +2,000 PTS)
     - 🎯 **擊破旗艦獎勵** (第一關 +20,000 PTS，逐關遞增)
     - 🏆 **1P / 2P 當前累積分數**
     - 🎖️ **戰役綜合評級 (Rank S / A / B / C)**
   - 點擊「進入下一關 (NEXT STAGE) ➜」即可繼續挺進！

7. **🔄 全五關戰役 ＋ 無限循環機制 (Infinite Loop System)**：
   - STAGE 1：重巡洋艦「利根」
   - STAGE 2：航空母艦「加賀」
   - STAGE 3：高速戰艦「金剛」
   - STAGE 4：裝甲空母「大鳳」
   - STAGE 5：超弩級戰艦「大和」
   - 第 5 關大捷後自動進入 **LOOP 2（二周目）**，保留所有分數、殘機與炸彈，敵軍速度與血量微幅增加 (+10%)，持續挑戰極限高分！

8. **💾 戰績保存、姓名輸入與 Top 10 排行榜**：
   - 遊戲結束（Game Over）時，主動詢問「是否保存您的英雄戰績至排行榜？」。
   - 輸入飛行員姓名（1~10 個字元）即可登錄於瀏覽器本地 Top 10 榮譽榜。
   - 隨時點擊頂部「🏆 英雄榜」可查看歷史戰績！
   - 隨時按 `P` 鍵重新投幣即可再次出發！

## 🎮 操控指南 (Controls)

| 動作功能 | 1P (藍色戰機) | 2P (紅色戰機) |
| :--- | :--- | :--- |
| **投幣** | 全域 **`P` 鍵** (單人投 1 枚 / 雙人投 2 枚) | 全域 **`P` 鍵** |
| **戰機移動** | **`W` (上) `A` (左) `S` (下) `D` (右)** | **方向鍵 `↑` (上) `←` (左) `↓` (下) `→` (右)** |
| **投放炸彈 (Mega Crash)** | **`B` 鍵** (全螢幕雷擊消彈 + 巨額傷害) | **數字 `1` 鍵** (主鍵盤 `1` 或九宮格 `1`) |
| **主砲射擊** | **`J` 鍵** 或 **`Space` (空白鍵)** | **`Enter` 鍵** 或 **數字 `0`** 或 **`K`** |
| **360° 特技翻滾 (迴避無敵)** | **`C` 鍵** | **數字 `2` 鍵** (主鍵盤 `2` 或九宮格 `2`) |
| **暫停遊戲** | **`ESC` 鍵** | **`ESC` 鍵** |

*提示：預設已開啟「⚡ 自動連射」，只要按住方向鍵或射擊鍵即可持續掃射，也可於控制台切換為手動單發。*
